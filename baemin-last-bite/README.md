# 마지막 한 입 다음 장면
VS Code에서 이 폴더를 열고 F5를 누르면 기본 브라우저에서 시연이 시작됩니다. Node.js 18 이상이 필요하며 패키지 설치는 필요하지 않습니다. 터미널 실행은 node server.mjs 입니다.
메뉴를 담고 장바구니의 짙은 녹색 체험 광고를 누르세요. 마지막 한 입을 터치하고 두 용기의 식사 후 장면을 비교한 뒤 선택을 장바구니에 적용할 수 있습니다.
src/app.js는 화면과 선택 흐름, src/scene.js는 메뉴 데이터와 식탁 그림, src/style.css는 디자인을 담당합니다.
